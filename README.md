This repository houses a 2D game I designed in Unity for an AP Biology assignment. 

You can play the game here: https://onyx310.github.io/Mitosis-Game/

This game is a competitive multiplayer game in which a randomly selected phase of Mitosis is shown and the selected player has to place the appropriate cellular components into the cell. 
The game checks if one of each necessary component is in the cell and rewards points based on how many items you correctly placed in the cell. 
If something is missing then it will show you on the review slide bar on the left. 

I wrote all of the scripts in C#.
